# 테트리스 + 3매치 퍼즐

테트리스로 블록을 쌓고 → 낱개로 쏟아진 블록이 애니팡처럼 자동 연쇄 → 60초 피버 타임에 직접 스와이프로 3매치를 노리는 단일 페이지 웹 게임입니다.

## 플레이
브라우저에서 `index.html`을 열면 바로 실행됩니다. (별도 설치·빌드 불필요)

**온라인 플레이:** https://jangyoungdo.github.io/tetris-match3/

## 조작
- **Phase 1 (쌓기):** ← → 이동 · ↑ 회전 · ↓ 빠르게 내리기 · Space 하드 드롭
- **Phase 2 (정렬):** 자동 진행
- **Phase 3 (피버 60초):** 인접한 두 블록을 클릭 & 드래그로 교환

## 참고
- 순수 HTML/CSS/JS 단일 파일, 외부 의존성 없음
- 🏆 명예의 전당은 `localStorage` 기반이라 **각 브라우저에만** 저장됩니다 (플레이어 간 공유 아님)
